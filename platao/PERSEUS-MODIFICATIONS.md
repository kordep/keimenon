# Public offer of the Republic transformations to Perseus

To the Perseus Digital Library project:

Keimenon offers the transformed Republic dataset and extraction code linked below for inspection and reuse under **CC BY-SA 4.0**. This public offer accompanies our use of your repository’s license statement and request that modifications be offered to Perseus.

- Dataset: [republic-data.js](republic-data.js)
- Transformation source: [tools/build-plato-corpus.py](tools/build-plato-corpus.py)
- Validation and source SHA-256 hashes: [corpus-validation.json](corpus-validation.json)
- Original Greek TEI used: [sources/republic-greek.xml](sources/republic-greek.xml)
- Original Shorey TEI used: [sources/republic-shorey.xml](sources/republic-shorey.xml)
- Full source attribution and transformation notes: [SOURCES.md](SOURCES.md)
- Upstream license statement preserved: [sources/PERSEUS-LICENSE-README.md](sources/PERSEUS-LICENSE-README.md)

The TEI input files are preserved as downloaded. The derivative display dataset matches explicit Stephanus section markers across Burnet, Shorey and the Jowett Gutenberg transcription, omits apparatus/editorial notes and normalizes whitespace. It does not translate, invent the Greek, or infer new passage boundaries using a language model.
